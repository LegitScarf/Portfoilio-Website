# Transform My Existing Portfolio into a Premium, Cinematic Developer & AI Engineer Portfolio

I have an existing personal portfolio website currently implemented as an `index.html` website and hosted through GitHub/GitHub Pages.

I want you to **completely redesign and transform the existing website**, while preserving and intelligently restructuring my existing content, projects, experience, skills, achievements, and links.

Use the attached/reference portfolio video as the **visual and interaction inspiration**.

The goal is NOT to make a generic developer portfolio.

The goal is to create a **premium, cinematic, modern personal brand website** that looks like the portfolio of a high-end AI Engineer / Data Analyst / Product Builder.

---

## 1. Core Design Direction

Create a website with the following aesthetic:

* Premium
* Cinematic
* Minimal
* Dark
* Futuristic but professional
* Editorial / magazine-inspired
* High-end SaaS/product aesthetic
* Strong typography
* Generous whitespace
* Subtle animations
* Smooth scrolling
* Sophisticated micro-interactions
* Visually impressive without becoming cluttered

The website should feel closer to a **premium digital product landing page** than a traditional résumé website.

Avoid:

* Generic Bootstrap portfolio layouts
* Excessive cards everywhere
* Bright gradients
* Overly colorful UI
* Excessive glassmorphism
* Stock illustrations
* Generic developer icons
* Huge walls of text
* Template-like layouts
* Unnecessary animations
* "AI-generated website" aesthetics

The design should communicate:

> "This person builds serious technology products and understands both engineering and business."

# 2. TECH STACK

Use a modern production-quality frontend stack.

### Primary Stack

* React
* TypeScript
* Vite
* Tailwind CSS
* Framer Motion
* Lucide React
* shadcn/ui where useful
* CSS custom properties for theming
* GitHub Pages for deployment

If the existing project is currently plain HTML/CSS/JS, migrate it into this React + TypeScript architecture rather than continuing to expand the single `index.html`.

### Recommended supporting libraries

Use only where they genuinely improve the experience:

* Framer Motion — animations and page transitions
* Lenis — smooth scrolling
* Lucide React — icons
* React Intersection Observer or equivalent — scroll-triggered animations

Do NOT add unnecessary dependencies.
